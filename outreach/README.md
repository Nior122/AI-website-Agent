# Outreach Preparation

Draft-only outreach uses the existing `TrackingStore` history and is eligible only after a qualified lead has a PASS validation, deployed preview URL, and approved human project review. Drafts are evidence-led, revision-preserving, and support EMAIL, WHATSAPP, INSTAGRAM, FACEBOOK, LINKEDIN, SMS, and OTHER formatting. `READY_TO_SEND` means approved for a future system only; this package has no sending capability.
